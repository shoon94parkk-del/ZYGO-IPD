분석 방법과 해석 범위

Vendor-neutral
Gradient IPD

Cx·∂Z/∂x, Cy·∂Z/∂y. 실제 pitch 기반의 기본 proxy입니다.

Radial / Tangential

중심 기준 벡터 성분을 분리해 팽창·수축과 회전형 signature를 구분합니다.

Polynomial residual

0–5차 global vector field를 적합해 보정 가능 성분과 residual을 비교합니다.

Zernike shape

defocus, astigmatism, coma 등 저차 형상 성분을 분해해 원인 탐색을 돕습니다.

비축대칭 응력에서는 단순 gradient 모델의 정확도가 제한될 수 있습니다. 이 화면의 결과는 연구·진단용이며, scanner 고유 CPE 또는 실제 nm IPD로 사용하려면 사내 overlay 데이터로 Cx/Cy 및 모델을 검증해야 합니다.
